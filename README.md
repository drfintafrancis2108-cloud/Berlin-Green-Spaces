# Mapping Land Use and Green/Open Spaces in Berlin

## Overview

This independent project explores the use of geospatial data to visualise land-use categories in Berlin. It is an initial practical exercise in GIS, spatial data handling, and map production using QGIS.

## Data

- **Source:** Berlin Environmental Atlas
- **Dataset:** Green and open-space inventory
- **Year:** 2021
- **Format:** GeoPackage (`.gpkg`)

## Workflow

1. Imported the spatial dataset into QGIS.
2. Explored the available land-use attributes.
3. Created a categorised thematic map using the `enutzung` field.
4. Prepared a print layout with a title, legend, and source note.
5. Exported the map as a PNG.

## Output

The exported map is available in the `outputs/` folder.

## Scope and limitations

This is an exploratory mapping exercise, not a completed environmental exposure assessment. The map visualises the categories recorded in the source dataset; it does not estimate individual exposure to green space or establish associations with health outcomes.
